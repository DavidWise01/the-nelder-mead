# THE NELDER-MEAD

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **KATÁBASIS**.

THE NELDER-MEAD SIMPLEX &mdash; a member of [[katabasis]]. A derivative-free optimizer: keep a simplex of n+1 points and transform its worst vertex through the centroid &mdash; REFLECT, EXPAND if excellent, CONTRACT if poor, SHRINK if stuck &mdash; oozing downhill on function values alone. Ideal for black-box / noisy / non-differentiable objectives. &#9670; LIT: a fail-loud check throws unless it reaches the minimum of (x&minus;3)&sup2;+(y&minus;2)&sup2; to 0.05. &#9650; AMBER: a heuristic &mdash; no convergence guarantee, stalls on ridges, poor past ~10 dims.
